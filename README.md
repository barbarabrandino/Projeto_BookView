# Bookview 📚

O **Bookview** é um aplicativo mobile de biblioteca virtual para organizar sua coleção de livros. Ele permite gerenciar seus dados localmente, realizando o CRUD completo (criar, ler, atualizar e deletar).

## 🚀 Tecnologias
* **React Native (Expo)**
* **TypeScript & JavaScript**
* **SQLite** (Banco de dados local)

## ⚙️ Funcionalidades
* Cadastrar novos livros (Título e autor)
* Listar todos os livros salvos
* Editar informações dos livros
* Remover livros da lista

## 📦 Como rodar o projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Entre na pasta:**
   ```bash
   cd bookview
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Inicie o Expo:**
   ```bash
   npx expo start
   ```

5. Abra o aplicativo **Expo Go** no celular e escaneie o **QR Code** gerado no terminal.
